# GameTop 🎮

Онлайн-магазин игровых цифровых товаров в Таджикистане.

## Категории
- Пополнение мобильных игр
- Цифровые подарочные карты
- Товары для компьютерных игр

## Как заказать
1. Выберите товар в каталоге.
2. Оформите заявку.
3. Дождитесь подтверждения заказа.
4. Получите товар после подтверждения оплаты.

## Поддержка
Контакты магазина будут добавлены перед запуском.

## Важно
Цены, наличие товаров и сроки выполнения должны быть подтверждены перед заказом.

GameTop — проект в разработке.
